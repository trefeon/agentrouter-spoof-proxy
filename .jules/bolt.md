## 2026-08-05 - Redundant JSON.parse on large request bodies
**Learning:** I found a redundant `JSON.parse` operation on the request body in `src/proxy/handler.mjs`. The request body (which can be up to 20MB) is first parsed in `summarizeRequest()` (which extracts the `model` into `requestSummary.model`), and then it was immediately parsed again on the very next lines just to extract the `model` for health marking (`let requestModel = null; try { requestModel = JSON.parse(fullBody.toString("utf8"))?.model || null; } catch {}`). Parsing a large JSON payload is a synchronous operation that blocks the Node.js event loop, so doing it twice is a significant performance penalty.
**Action:** Always check if data being parsed has already been parsed earlier in the execution path, especially on large payloads.
